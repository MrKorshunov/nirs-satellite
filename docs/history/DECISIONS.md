# Принятые решения и допущения

1. **Сначала один КА.** Затем несколько КА и выбор конфигурации группировки.
2. **Первое ядро не зависит от орбитального движка.** Оно принимает временные
   интервалы операций; реальные окна подключаются позже через адаптер.
3. **Никаких заимствований из GitVerse до проверки лицензии и корректности.**
   В версии 0.1 исходники оригинала не копировались.
4. **Точное определение успеха:** съёмка завершена, продукт полностью
   принят на Земле не позднее дедлайна. Передача после срока — не успех.
5. **Память:** продукт удерживает полный объём до завершения передачи;
   это консервативное допущение, не подтверждённая архитектура бортового ПО.
6. **Один канал / один КА:** съёмка и передача не совмещаются; пересекающиеся
   окна связи запрещаются; накладывающиеся съёмки считаются ошибкой входа.
7. **Планирование v0.1:** заданные съёмки и два порядка передачи (FIFO и EDF),
   не оптимизация наблюдений. Прогнозирование орбиты пока не требуется.
8. **Метрика K:** сумма весов выполненных вовремя заданий / сумма весов
   всех заданий. При пустом наборе заданий программа условно возвращает 0.
9. **Демо:** данные полностью синтетические, не выдаются за реальные
   характеристики HyperScape100, КА или наземной станции.
10. **Состав исходной группы библиотек не наследуем.** Для v0.1 достаточно
    Python 3.11+ без дополнительных зависимостей.
