# Откуда берутся исходные данные

## Статус данных v0.1.1

**Все входные значения в `scenarios/demo.json` — искусственные.** Они заданы разработчиком для воспроизводимого контрольного примера. Ни одно значение не вычислено из орбитальной модели или паспорта реального КА.

| Параметр | В JSON | Значение в удобных единицах | Происхождение |
|---|---|---|---|
| Память | `memory_capacity_bytes` | 180 000 000 байт = 180 МБ | Синтетическое допущение |
| Объём каждого снимка | `tasks[].volume_bytes` | 90 000 000 байт = 90 МБ | Синтетическое допущение |
| Съёмка A | `capture_start_s`, `capture_end_s` | 3–5 мин | Синтетическое окно |
| Съёмка B | то же | 8–10 мин | Синтетическое окно |
| Съёмка C | то же | 18–20 мин | Синтетическое окно |
| Дедлайн A | `deadline_s` | 150 мин | Синтетическое требование |
| Дедлайн B | то же | 75 мин | Синтетическое требование |
| Дедлайн C | то же | 110 мин | Синтетическое требование |
| Контакт 1 | `contacts[0]` | 45–75 мин | Синтетическое окно |
| Контакт 2 | `contacts[1]` | 90–120 мин | Синтетическое окно |
| Скорость связи | `rate_bytes_per_s` | 50 000 байт/с = 0,4 Мбит/с | Синтетическое допущение |
| Важность заданий | `priority` | 1 для каждого | Равные веса для проверки |

**Единицы:** 1 МБ = 1 000 000 байт; 1 Мбит = 1 000 000 бит; 1 байт = 8 бит. Время — секунды от условного старта эксперимента. Важность (`priority`) используется только в расчёте итогового коэффициента K, не в FIFO/EDF.

## Что нужно для физически обоснованных данных

1. **Орбитальные окна:** параметры орбиты, эпоха, геодезические координаты целей/станций, минимальная высота цели, геометрия наведения; нужны расчёт и независимая проверка.
2. **Объём изображений:** параметры аппаратуры, разрешение, число каналов, разрядность, упаковка, размер отснятой области; формула и источник каждого параметра.
3. **Память:** доступный полезный объём и организация буферов, подтверждённые паспортом/архитектурой; реальный алгоритм освобождения памяти.
4. **Связь:** радиолиния, модуляция, наземная станция, направленность антенны, протокол и полезная скорость, подтверждённые расчётом.
5. **Сроки:** требования заказчика/сценария, честно обозначенные как нормативные, исследовательские или условные.

**Правило:** у каждого нового параметра фиксировать название, значение, единицу, источник/ссылку, версию источника, статус (паспорт/расчёт/предположение) и неопределённость.
