# Карта файлов проекта

| Файл / папка | Что делает | С чем связан |
|---|---|---|
| `scenarios/demo.json` | **Входные** числа контрольного примера | Читает `main.py`, `explain.py` |
| `main.py` | Загружает сценарий, выполняет две политики, сохраняет CSV/JSON | Вызывает `nirs_satellite/engine.py` |
| `nirs_satellite/model.py` | Описывает сущности `Task`, `Contact`, `Scenario` и проверяет ограничения входа | Используется движком |
| `nirs_satellite/engine.py` | Дискретно-событийная модель памяти и передачи | Возвращает `Result`: события, память, выполненные/пропущенные задания |
| `explain.py` | **Показывает расчёт**, формирует `results/report.html` без внешних библиотек | Читает тот же сценарий и запускает тот же движок |
| `tests/test_engine.py` | 14 проверок модельной логики | `python -m unittest discover -s tests -v` |
| `tests/test_explain.py` | Проверка генерации прозрачного отчёта | Та же команда |
| `results/` | Фактический результат тестового прогона | Не источник исходных чисел |
| `docs/INPUT_DATA.md` | Происхождение параметров и их единицы | Важен для научной достоверности |
| `docs/MODEL_STEP_BY_STEP.md` | Как получаются результаты FIFO и EDF | Помогает защитить/объяснить модель |
| `TASKS.md` | Выполненные и предстоящие задачи | Будущие Git Issues |
| `PROJECT_STATE.md` | Что реально сделано и протестировано | Обновлять после этапа |
| `CHANGELOG.md` | Хронология версий | Связать с коммитами Git |
| `DECISIONS.md` | Принятые решения и допущения | Нельзя путать с подтверждённой физикой |

## Что в этой модели **не** оптимизируется

Все съёмки уже заданы в `demo.json`. Программа сравнивает только два **порядка передачи** накопленных продуктов. Самостоятельный выбор целей, времён съёмки и группировки — задача следующих версий.
