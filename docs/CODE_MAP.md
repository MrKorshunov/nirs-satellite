# Карта кода НИРС

Это **карта действующего репозитория**; старый прототип перенесён в `archive/v01`.

| Папка / файл | Зачем нужен | Что НЕ следует делать |
| --- | --- | --- |
| `START_NIRS.cmd` | Запустить русское окно | Не менять для экспериментов |
| `SETUP_NIRS.cmd` | Один раз установить зависимости в `.venv` | Не запускать при каждом расчёте |
| `CHECK_NIRS.cmd` | Автоматические тесты + короткий физический запуск | Не считать заменой калибровки |
| `nirs_satellite/launcher_gui.py` | Кнопки запуска, остановки, результаты, Vizard | Не хранить в нём числа КА |
| `nirs_satellite/input_paths.py` | Единый реестр источников всех входных JSON | Не дублировать пути в экспериментах |
| `nirs_satellite/input_editor.py` | Редактор входных данных, резервные копии | Проверка формата не равна физической валидации |
| `inputs/physical/` | Параметры физического одиночного КА | Не смешивать с Mission 02 |
| `inputs/research/` | Параметры условной многозадачной проверки | Не переносить результаты на реальный КА |
| `experiments/orbit_01/` | Базовая орбита, численная/аналитическая проверка | Двухтельная модель не равна реальной орбите |
| `experiments/ground_01/run_ground.py` | Главный интегратор: собирает Basilisk, геометрию, ADCS, приборы, Power 01 и Vizard | Не редактировать без регрессионных тестов |
| `experiments/adcs_02/` | Реакционные маховики Basilisk и диагностика | Параметры синтетические, нет магнитной разгрузки |
| `experiments/power_01/` | Eclipse, SolarPanel, Battery, PowerSink Basilisk | Заряд не управляет выключением приборов |
| `experiments/mission_01/` | Один сквозной снимок с хранением и передачей | Не планировщик множества заданий |
| `experiments/mission_02/` | Несколько задач, упрощённые ресурсные ограничения, FIFO / EDF / Priority и sweep | Не полное физическое выполнение расписания |
| `experiments/adcs_01/`, `experiments/payload_01/` | Проверенные ранние изолированные тесты; оставлены для регрессии | Не основные рабочие режимы |
| `tests/` | Математические, интерфейсные и входные тесты | Не заменяют натурную валидацию |
| `docs/` | Технические пояснения, ограничения, результаты и источники | Исторические отчёты могут описывать ранний этап |
| `archive/v01/` | Учебный FIFO/EDF без орбиты и энергетики | Не актуальная модель спутника |

## Точки входа для разработчика

- Физический один КА: `python -m experiments.mission_01.run_mission --actuator rw --power`.
- Многозадачная проверка: `python -m experiments.mission_02.run`.
- Эксперименты по сетке параметров: `python -m experiments.mission_02.sweep --track ...`.
- Отладочный орбитальный модуль: `python -m experiments.orbit_01.run_orbit`.
- Архивный образец: `python -m archive.v01.main` — **не** основной спутник.

Для обычного пользователя эти команды не нужны: предусмотрена графическая программа.

## Почему модули `experiments/` не перемещены в новую Python-папку

Это реальные импортируемые пакеты, на которые ссылаются Bash/PowerShell-проверки, Python-модули, загрузка данных и тесты. Перенос ради косметики сломал бы уже подтверждённые физические запуски. Вместо этого разделены **пользовательские данные**, **действующий код** и **архив**; прежние имена модулей сохранены для воспроизводимости.
