# С чего начать — НИРС

## Идея за две минуты
Исследуем, как **планирование целевых операций** космического аппарата (КА) влияет на долю заданий, для которых данные были получены и доставлены в срок; затем проверим влияние планировщика на необходимый состав группировки.

**Два уровня исследования:**
1. При фиксированном составе КА сравнить расписания съёмок и передачи данных.
2. При одинаковой программе наблюдений определить, как меняется необходимое число КА при разных алгоритмах планирования.

Научная новизна **пока не доказана**. Отдельный научный обзор не заменяет эксперимент.

## Что уже работает
- Код: `nirs_satellite/model.py`, `nirs_satellite/engine.py`.
- Запуск: `py main.py`, затем `py explain.py`.
- Тесты: `py -m unittest discover -s tests -v`.
- Вход: `scenarios/demo.json` (полностью **синтетические** значения).
- Отчёт: `results/report.html` после запуска `py explain.py`.

**На текущем этапе:** снимки уже запланированы, модель воспроизводит хранение, передачу и соблюдение сроков; FIFO и EDF выбирают порядок передачи, **не моменты съёмки**. Реальные орбиты, энергия и группировка пока отсутствуют.

## Главное правило
Каждая цифра — значение + единица + источник + степень достоверности; каждый эксперимент — конфигурация + версия программы + журнал событий + проверки. «Программа запустилась» не равно «физическая модель валидирована».
