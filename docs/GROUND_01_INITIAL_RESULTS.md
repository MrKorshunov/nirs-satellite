# Ground 01 — первые подтверждённые результаты

**Дата проверки:** 06.11.2026. **Источник:** [GitHub Actions #42240068517](https://github.com/MrKorshunov/nirs-satellite/actions/runs/42240068517), джобы `basilisk-orbit-smoke`, `basilisk-windows-unicode-path`, `unit-tests`. Проверка выполнялась на временных виртуальных машинах GitHub, **не** на компьютере пользователя.

## Исходная конфигурация

Точные машинно-читаемые исходные данные находятся в [config.json](../experiments/ground_01/config.json), исходный orbit-01 — [orbit config](../experiments/orbit_01/config.json).

- Орбита: синтетическая двухтельная круговая, начальная высота 500 км, наклонение 45°, RAAN 30°.
- Наземная цель: синтетические широта 14°, долгота 43°, высота 0 м, минимальный угол места 10°.
- Земля: сфера радиусом 6 378 137 м, заданное постоянное вращение `7.292115e-5 rad/s`, **не существует привязки нулевого меридиана к UTC**.
- Длительность: один расчётный виток, шаг 10 с.
- Подключённые готовые компоненты: Basilisk 2.12.2 — `spacecraft`, `planetEphemeris`, `groundLocation`.

## Как самому воспроизвести на Windows

```powershell
.\.venv\Scripts\python.exe -m experiments.ground_01.run_ground
Invoke-Item .\results\ground_01\elevation.png
Invoke-Item .\results\ground_01\slant_range.png
notepad .\results\ground_01\summary.json
```

Отчёты не хранятся в Git автоматически, но конфигурация и код сохранены, чтобы воспроизводить их. Точные времена окна и границы дискретизации нужно извлечь из пользовательского `summary.json` после его запуска и отдельно проверить перед фиксацией следующего результата.

## Научные ограничения

1. Вращение Земли упрощено постоянной угловой скоростью, начальная ориентация синтетическая; нет датированного реального пролёта.
2. Земля — сфера, рельеф и атмосферная рефракция отсутствуют.
3. Видимость только геометрическая: никаких FOV, наведения, допустимых углов съёмки, освещённости, облачности, бортовой памяти и радиоканала.
4. Границы окна дискретны, ошибка определения времени перехода оценивается порядком шага (10 с); уточнение по интерполяции — отдельная работа.
5. `PASS` отражает заранее определённые критерии модели; не является валидацией по независимой орбитальной телеметрии.

## Следующий инженерный шаг

После подтверждения на пользовательском Windows: проверить реальные значения начала и конца окна, открыть графики, затем аккуратно добавить отображение наземной цели в Vizard **с согласованной моделью вращения Земли**. После этого подключать полезную нагрузку и её физические ограничения.
