## Контрольная версия Mission 05

- Контрольный коммит: `c65daa80c6612a876575337b39f9150223a3c531`.

**GitHub Actions не подтверждены:** четыре workflow для указанного коммита оставались в статусе `queued` на дату проверки. Это не успешные CI-проверки и не результат локального прогона.

## Что уже реализовано

| Область | Состояние |
| --- | --- |
| Орбита, наведение, маховики, камера, память, батарея и радиопередача | Исполняются физическими модулями Basilisk на условных параметрах |
| Mission 03 | Проверенный регрессионный сценарий двух последовательных точечных заданий |
| Mission 04 | Универсальный физический исполнитель заранее упорядоченных точечных и полосных заданий |
| Mission 05 | План/факт окон, WGS84-оценка геометрического покрытия, UTC/приближённый GMST и приёмка 16/16 |
| Mission 02 | Отдельное сравнение FIFO/EDF/Priority с приближённой ресурсной моделью на орбитальном треке Basilisk |

**Планировщика для физической модели пока нет.** Исполнитель Mission 05 воспроизводит заданный порядок, а не выбирает его.

## Обновление и запуск в Windows

Инструкция GitHub Desktop: [GIT_WINDOWS.md](GIT_WINDOWS.md). После обновления исходников запускать `START_NIRS.cmd`; если менялись зависимости — сначала `SETUP_NIRS.cmd`. Полная приёмка Mission 05 — `CHECK_RESEARCH_READY.cmd`; общий набор проверок и короткие физические запуски — `CHECK_NIRS.cmd`.
