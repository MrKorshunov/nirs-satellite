# Архив ранних экспериментов

`v01/` — исторический самостоятельный прототип планирования FIFO/EDF, созданный **до** подключения Basilisk, орбиты и физической энергетики.

Содержит ранние `main.py`, `explain.py`, `model.py`, `engine.py`, `demo.json` и контрольные HTML/CSV/JSON отчёты из старых расчётов. Сохранён для проверки происхождения проекта и для сравнения методики, **но не является текущей физической моделью спутника**.

Запуск архивного примера (только разработчику):
`python -m archive.v01.main` или `python -m archive.v01.explain` из корня проекта. Новые результаты записываются в папку `results/legacy_v01/`.

Основные рабочие сценарии находятся в `experiments/mission_01/` и `experiments/mission_02/`.
