# Исходные данные — единственное место для параметров

**Менять численные данные нужно здесь, а не в Python-коде.**

- [physical/](physical/) — физический одиночный КА: орбита, Земля, цель, маховики, энергия, снимок, память, радиоканал; два файла помечены `_legacy` и нужны только для старых проверок.
- [research/](research/) — самостоятельная упрощённая многозадачная модель для первых экспериментов.

**Как изменить:** `START_NIRS.cmd` → «Все исходные данные» → выбрать понятное русское описание файла → отредактировать JSON → проверить → сохранить (предыдущая версия автоматически станет `.bak`).

Формат JSON не допускает комментариев `//` и десятичной запятой. Укажите числа с точкой, например `0.01`. Величины имеют единицы непосредственно в названиях полей.

## Связность источников

Физический `ground_01` читает `earth_target.json`, а из него относительно той же папки — `orbit.json`. Модули ADCS, Power, Mission ссылаются на собственные конфигурации через общий реестр `nirs_satellite/input_paths.py`, чтобы не хранить копии параметров в `experiments/`.

**Это два независимых экспериментальных профиля:** численно одинаковое поле памяти в `physical/camera_storage_radio.json` и `research/observation_tasks.json` не делает их связанными. При желании сравнить подробный физический КА и упрощённый планировщик входные числа необходимо явно согласовать.

Полное описание параметров: [docs/INPUT_DATA.md](../docs/INPUT_DATA.md).
