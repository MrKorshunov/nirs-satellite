# НИРС — исследовательская модель спутника ДЗЗ

**Цель:** исследовать выполнение заданий наблюдения Земли с учётом геометрии, наведения, памяти, энергетики и передачи данных. Все исходные параметры пока **условные**, а не паспорт конкретного КА.

## Быстрый запуск на Windows

1. Один раз откройте двойным щелчком **SETUP_NIRS.cmd** — установится локальная среда Python 3.13 и Basilisk 2.12.2.
2. Каждый следующий раз открывайте **START_NIRS.cmd** — появится русское окно программы.
3. Выберите физический спутник (один условный снимок) либо многозадачный контрольный эксперимент и нажмите «Запустить».
4. Для проверки всего проекта используйте **CHECK_NIRS.cmd**. Отчёты и графики — в локальной папке **results/**; файл воспроизведения Vizard — через кнопку «Папка Vizard».

**[Подробная инструкция для Windows](docs/WINDOWS_GUI_GUIDE.md).** Программа не требует VS Code или PowerShell при обычном запуске.

## Состояние модели

- **Physical / Mission 01**: орбита и вращение корпуса Basilisk, управление тремя реакционными маховиками, синтетическая наземная цель, затмение, солнечная панель, аккумулятор, **одна условная съёмка** 1 МБ, память и передача данных, Vizard.
- **Mission 02**: несколько условных заданий, две станции и сравнение FIFO / EDF / Priority на орбите, предварительно рассчитанной Basilisk. Ограничения поворота, энергии и радиоканала здесь **приближённые**: каждую команду не исполняют физические модули Basilisk.

**Это уже работоспособная исследовательская платформа, но не высокоточный цифровой двойник реального КА и пока не единая многозадачная физическая модель.** Программное ограничение энергопитания, физическое перенаведение на много целей, датчики, реальная оптика и приём сигнала ещё требуют работы.
