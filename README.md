# НИРС — планирование целевых операций КА и оценка группировок

**Статус:** проверяемый синтетический прототип v0.1.1, физическая модель и оптимизатор съёмок ещё не подключены.

> **Новому участнику:** откройте [«С чего начать»](docs/START_HERE.md), затем [архитектуру](docs/ARCHITECTURE.md) и [реестр открытых источников](docs/SOURCE_REGISTER.md). Все результаты v0.1.1 получены на искусственных входных данных.

## Начало работы на Windows

```powershell
py main.py
py explain.py
py -m unittest discover -s tests -v
start .\results\report.html
```

Текущий код использует только стандартную библиотеку Python; следующий физический/оптимизационный этап будет выполняться в отдельном окружении Python 3.13. Установка внешних научных пакетов ещё не выполнена.

## Что находится в репозитории

- `nirs_satellite/`: модель заданных съёмок, памяти и передачи; сравнение очередей FIFO и EDF.
- `scenarios/demo.json`: **синтетический** контрольный сценарий (НЕ паспорт реального КА).
- `tests/`: автоматические тесты.
- `docs/INPUT_DATA.md`, `docs/MODEL_STEP_BY_STEP.md`: происхождение чисел и пошаговая трассировка.
- `results/`: результаты демонстрации (в будущем разделим эталонные и генерируемые).
- `TASKS.md`, `PROJECT_STATE.md`, `DECISIONS.md`, `CHANGELOG.md`: план, статус, решения, версии.

## Что исследуем

1. При заданном составе спутников сравнить методы планирования наблюдений и передачи данных для максимизации доли заданий, доставленных в срок.
2. Определить, как изменение метода планирования влияет на минимальную численность группировки для одной и той же программы наблюдений.

Не путать работающий прототип с физически валидированной спутниковой моделью. На v0.1.1 программа **не выбирает окна съёмок**, а только порядок передачи уже назначенных продуктов. Технические и научные ограничения см. [START_HERE](docs/START_HERE.md).

## Первое физическое исследование (экспериментальная ветка)

Пилот орбитального движения на **Basilisk**: [эксперимент 01](experiments/orbit_01/README.md). Он должен создать таблицу состояний и графики, а также файл воспроизведения Vizard при доступном модуле. **На Windows расчёт запущен успешно, графики открыты, файл `orbit_01.bin` воспроизведён в Vizard (05.11.2026).** Это ещё не доказывает точность реальной орбиты.

Как проверить рассчитанные координаты и где лежит код Basilisk: [проверка орбиты и карта исходников](docs/ORBIT_VALIDATION_AND_CODE.md).
