# ADCS 02 — физические маховики Basilisk

В отличие от ADCS 01 с идеальным внешним моментом, модуль использует
штатные `reactionWheelStateEffector`, `rwMotorTorque` и `simIncludeRW`.

## Запуск

Из корня проекта с Basilisk 2.12.2:

```powershell
.\.venv\Scripts\python.exe -m experiments.ground_01.run_ground --adcs --actuator rw --duration-hours 0.2 --step-s 0.5 --output-name adcs02_local
```

Для совместного прогона синтетической съёмки, памяти и радио:

```powershell
.\.venv\Scripts\python.exe -m experiments.mission_01.run_mission --actuator rw --viz-mode file --viz-step-s 10 --output-name mission01_rw_trial
```

**Эта последняя комбинация пока не является отдельно принятой версией**, пока
не пройдёт физический CI именно с обоими режимами.

## Что моделируется

Три взаимно ортогональных кастомных балансированных колеса;
каждое: инерция 0.0005 кг·м², предельный момент 0.01 Н·м,
предельная скорость 950 об/мин. Запрос момента рассчитан MRP feedback,
исполнительные команды распределяются штатным модулем rwMotorTorque.

Журналы `adcs02_reaction_wheels.csv`, `adcs_summary.json`,
`adcs_pointing.png` позволяют проверить действительные скорости и
ориентацию, а не одни запрошенные моменты.

Проведён автоматический Linux CI (ADCS02), зафиксирована фактическая
максимальная скорость около 447.75 об/мин. Это измерение только
для **выбранного теста**, без реальных характеристик маховиков.

## Ограничения

- Параметры синтетические; оси/колёса не представляют серийную модель.
- Нет магнитных катушек, разгрузки кинетического момента и шумов датчиков.
- Пока выполняется наведение на одну цель, не полный физический replay
  нескольких независимых команд Mission 02.
- Жёсткая модель корпуса, упрощённая навигация.
- Не следует оценивать энергопотребление этих колёс через фактическое
  потребление без отдельной откалиброванной энергетической модели.

Официальный пример:
https://avslab.github.io/basilisk/examples/scenarioAttitudeFeedbackRW.html
