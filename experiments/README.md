# Расчётные модули и сценарии

Это **Python-код**, который подключает и проверяет модули Basilisk. Численные начальные данные вводятся **не здесь**, а в [inputs/](../inputs/README.md).

| Подкаталог | Статус | Что выполняет |
| --- | --- | --- |
| `orbit_01/` | Базовый физический тест | Движение КА, сравнение численного решения с аналитическим |
| `ground_01/` | **Общий физический запуск** | Собирает динамику, вращающуюся Землю, цель/станцию, ADCS, Payload/Power и Vizard |
| `adcs_02/` | **Основной физический ADCS** | Маховики с ограничениям момента и скорости |
| `power_01/` | **Основная физическая энергетика** | Затмение, генерация панели, потребление, аккумулятор; пока без отключения приборов |
| `mission_01/` | **Сквозной одиночный КА** | Один условный снимок, память и передача данных |
| `mission_02/` | **Контрольное планирование** | Несколько задач, ограниченные условные ресурсы, FIFO/EDF/Priority, серии экспериментов |
| `adcs_01/` | Старый проверочный сценарий | Динамика корпуса с неограниченным внешним моментом |
| `payload_01/` | Старый проверочный сценарий | Изолированная генерация условного продукта без физического наведения |

Для повседневной работы используйте графический интерфейс `START_NIRS.cmd`. Сложную систему не следует собирать повторно из каждого модуля вручную.

Главный Python-процесс физического эксперимента сейчас находится в `ground_01/run_ground.py`. Его имя историческое, но модуль фактически объединяет все физические подсистемы. Перенос/разделение этого большого файла — будущий технический рефакторинг и требует дополнительных регрессионных тестов.
